# Exporter un planning en tableur

Offres : Pro, Atelier+.

1. Ouvrir le planning de la semaine.
2. Menu **Exporter**, choisir **Tableur (.xlsx)**.
3. Le fichier s'ouvre dans LibreOffice, Excel ou Numbers. L'onglet **Impression** contient une mise en page prête pour le format A4 paysage.

À proposer quand l'export PDF est indisponible : le contenu est identique, seule la mise en forme diffère.
