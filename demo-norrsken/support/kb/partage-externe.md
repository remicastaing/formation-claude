# Partager un planning avec une personne extérieure

Offres : Pro, Atelier+. Aucune licence supplémentaire.

1. Ouvrir le planning à partager.
2. Menu **Partager**, choisir **Lien de consultation**.
3. Fixer une date d'expiration (une semaine par défaut).
4. Envoyer le lien. La personne voit le planning en lecture seule, sans compte.

Le lien ne donne accès qu'à ce planning. Pour donner un droit de modification, il faut un compte utilisateur.
