# Étendre Claude Code — formation

Préparation complète d'un cours de 3 h 30 sur les six mécanismes d'extension de Claude Code (CLAUDE.md, skills, sous-agents, MCP, hooks, plugins), pour une équipe de développeurs et une équipe commerciale et support réunies.

- **Le cours écrit** : https://remicastaing.github.io/formation-claude/
- **Le support de présentation** : https://remicastaing.github.io/formation-claude/slides/ ([PDF](https://remicastaing.github.io/formation-claude/slides/slides.pdf))
- **Le kit des participants** : https://github.com/remicastaing/norrsken-demo (dépôt de démo, squelettes, TP ; généré automatiquement, sans les notes du formateur)

| Dossier | Contenu |
|---|---|
| `plan-cours-extensions-claude-code.md` | Le plan de référence |
| `modules/` | Notes du formateur, un fichier par module |
| `scripts/` | Texte oral, slide par slide |
| `supports/` | Slides Marp, figures, illustrations |
| `cours/` | Le cours écrit, livre Quarto |
| `tp/` | Travaux pratiques, distribués aux participants |
| `participants/` | Grille, quiz, fiche d'engagement, squelettes de fichiers |
| `demo-norrsken/` | Le dépôt de démo : application avec bugs plantés, tickets, configuration cible, catalogue de plugins |
| `logistique/` | Matériel, démos du formateur, réponses attendues |
| `style/` | Charte rédactionnelle et graphique, thème Marp |

Le cas fil rouge, Norrsken, est entièrement fictif. Le vault se lit dans Obsidian ; `CLAUDE.md` décrit l'organisation et la marche à suivre pour Claude Code.

Rendu local : `supports/README.md` (Marp) et `cours/README.md` (Quarto).
