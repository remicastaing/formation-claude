# Point à J+15 — canevas

Une heure, tous ensemble ou par équipe. Objectif : comparer ce qui a réellement été construit avec les engagements de la clôture, et faire évoluer le plugin d'équipe.

## Avant

- Retrouver la liste des engagements notée au tableau à la clôture (photo prise en fin de séance) et les fiches.
- Demander à chacun d'apporter son fichier : le CLAUDE.md, le skill, le hook, tel quel.
- Préparer le dépôt du catalogue d'équipe (git interne) si ce n'est pas fait ; y verser `demo-norrsken/marketplace/` comme point de départ.

## Déroulé

| Min | Séquence |
|---|---|
| 0–25 | Tour : chacun montre ce qu'il a construit face à son engagement. Une phrase sur ce qui a marché, une sur ce qui a bloqué. Pas de jugement ; noter les blocages. |
| 25–40 | Tri des blocages : formulation (souhait vs contrainte), description de skill, accès manquant, garde-fou dans un prompt. Chaque blocage renvoie à un module ; le nommer. |
| 40–55 | Le plugin d'équipe : ce qui est réutilisable parmi les fichiers apportés entre dans `norrsken-support` ou `norrsken-dev`. Nommer un responsable par plugin. Passer la version à 1.1.0. Installer chez tout le monde. |
| 55–60 | Le prochain ajout collectif, un seul, et sa date. |

## Ce qu'on regarde

- Combien d'engagements tenus, et lesquels ne l'ont pas été : le mécanisme en cause dit où le cours n'a pas suffi.
- Les CLAUDE.md apportés : longueur, souhaits vs contraintes.
- Les descriptions de skills : les trois parties y sont-elles ?
- Les garde-fous : lesquels sont restés dans un prompt.

## Après

- Le catalogue mis à jour, la commande d'installation envoyée à tous.
- Une ligne par participant : engagement, tenu ou non, blocage. À garder pour la prochaine session.
